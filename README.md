# Little Love Garden ♡

เว็บขอเป็นแฟนธีมชมพูและกระต่าย ใช้ HTML / CSS / JavaScript ไม่มีขั้นตอนติดตั้งหรือฐานข้อมูล

## เปิดในเครื่อง

วางโฟลเดอร์ `bunny-love` ใน `C:\xampp\htdocs` เปิด Apache ใน XAMPP แล้วเข้า http://localhost/bunny-love/ หรือดับเบิลคลิก index.html ได้ทันที

## แก้รูป ชื่อ และข้อความ

เปิด `config.js` ด้วย VS Code หรือ Notepad แล้วบันทึกเป็น UTF-8:

- `recipient` ชื่อเธอ / `sender` ชื่อคุณ
- `photoUrl` ลิงก์ภาพโดยตรงจาก Discord หรือชื่อไฟล์ เช่น `assets/our-photo.jpg`
- `photoCaption` คำบรรยายรูป
- `texts` ข้อความแต่ละส่วน แก้เฉพาะด้านขวาในเครื่องหมายคำพูด ใช้ `\n` ขึ้นบรรทัดใหม่
- `notReadyMessage` ข้อความเมื่อเธอขอเวลา
- `noPhotoTitle` หัวข้อของขวัญเมื่อยังไม่ได้ใส่รูป

อัลบั้มจะปรากฏในของขวัญและกรอบความทรงจำ ถ้ายังไม่มีรูปจะใช้สวนกระต่ายที่แถมมา ถ้ารูปเปิดไม่ได้จะมีภาพสำรองและข้อความแจ้ง ถ้าข้อความใหม่ยังไม่ปรากฏ ให้รีเฟรชด้วย Ctrl+F5

ใช้ลิงก์ตัวรูปจาก Discord ไม่ใช่ลิงก์ข้อความหรือห้องสนทนา หากวันหลังลิงก์เปิดไม่ได้ ให้แทนที่ด้วยลิงก์ใหม่หรือบันทึกรูปไว้ใน assets เพื่อไม่ต้องพึ่งลิงก์ภายนอก

## ใช้กับ GitHub Pages

นำไฟล์ทั้งหมดภายในโฟลเดอร์นี้ขึ้น repository โดยให้ index.html อยู่ระดับบนสุด ตั้ง GitHub Pages ให้เผยแพร่จาก branch ที่เก็บไฟล์และโฟลเดอร์ root ไม่ต้องใช้ npm หรือ build มี .nojekyll มาให้แล้ว

## สิ่งที่มี

ฉากเปิดเต็มจอ / ภาพสวนกระต่ายเฉพาะเว็บ / หัวใจฉลอง / การเผยเนื้อหาขณะเลื่อน / กล่องของขวัญ / รูปจากลิงก์ / จดหมาย / คำถามพร้อมสองคำตอบ / ดนตรีสังเคราะห์เปิดปิดได้ / รองรับมือถือ คีย์บอร์ด และการลดแอนิเมชันตามระบบ

เว็บพยายามเริ่มเสียงเมื่อเปิดหน้า หากเบราว์เซอร์บล็อก จะเริ่มเมื่อกดเปิดประตูหัวใจ ปิดได้จากปุ่มเสียง ตั้ง autoPlayMusic เป็น false ใน config.js เพื่อปิดการเริ่มอัตโนมัติ ไม่มีการส่งคำตอบออกจากเครื่องหรือเก็บข้อมูลผู้ชม ฟอนต์โหลดจาก Google Fonts หากออฟไลน์จะใช้ฟอนต์ระบบ ตัวเว็บยังทำงานได้

ปรับรูปลักษณ์ใน style.css และโครงสร้างใน index.html ได้ตามต้องการ

## อัลบั้มหลายรูป

แก้ `photos` ใน config.js ใส่ลิงก์ใน `url` และข้อความใต้รูปใน `caption` มีช่องเตรียมไว้ 5 รูป เพิ่มหรือลบรายการได้ ระบบจัดวางตามจำนวนรูป ช่องว่างจะไม่แสดง ใช้ไฟล์ใน assets ได้เช่นกัน เช่น `assets/photo-1.jpg`

คลิกรูปเพื่อขยาย ใช้ปุ่มลูกศร ปุ่มลูกศรบนคีย์บอร์ด หรือปัดซ้ายขวาบนภาพเพื่อดูรูปถัดไป กด “ดูทั้งอัลบั้ม” เพื่อย้อนกลับ กด Escape เพื่อปิด ไม่เลื่อนอัตโนมัติเพื่อให้อ่านคำบรรยายได้เต็มที่ หาก photos ว่างทั้งหมด จะใช้ photoUrl เดิมแทน

## จดหมาย เสียง และฉากจบ

- ซองจดหมายหลัก: กดแกะซองเพื่ออ่านข้อความเดิมของคุณ เปลี่ยนข้อความหน้าซองที่ envelopeMessage และ envelopeButton
- จดหมายตามความรู้สึก: แก้ openWhenLetters แต่ละรายการมี icon, title, message ใช้ \n ขึ้นบรรทัดใหม่ได้
- เสียงของคุณ: อัดเสียงแล้วบันทึกไฟล์ไว้ใน assets เช่น my-voice.mp3 จากนั้นตั้ง voiceUrl เป็น assets/my-voice.mp3 รองรับลิงก์ไฟล์เสียงโดยตรงด้วย ยังไม่มีไฟล์เสียงจริงแถมมาให้ เมื่อไม่ใส่ไฟล์จะแสดงข้อความรอเสียง สามารถตั้ง voiceTranscript เป็นข้อความถอดเสียงได้
- เพลงพื้นหลังพักระหว่างฟังเสียงอัด และกลับมาเมื่อหยุดหรือฟังจบ หากก่อนหน้านั้นยังเปิดเพลงไว้
- ฉากจบ: ใช้ sender และ recipient เป็นชื่อบนฉาก แก้ข้อความที่ finaleMessage หลังตอบตกลงจะเข้าฉากจบ กดไปต่อหรือข้ามเพื่อดูข้อความขอฟอลไอจี
- เมื่ออัปเดต GitHub ให้อัปโหลด index.html, app.js, extras.js, style.css, config.js รวมทั้งไฟล์เสียงใน assets ที่เพิ่มเอง
