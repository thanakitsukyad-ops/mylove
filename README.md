# Little Love Garden ♡

เว็บขอเป็นแฟนธีมชมพูและกระต่าย ใช้ HTML / CSS / JavaScript ไม่มีขั้นตอนติดตั้งหรือฐานข้อมูล

## เปิดในเครื่อง

วางโฟลเดอร์ `bunny-love` ใน `C:\xampp\htdocs` เปิด Apache ใน XAMPP แล้วเข้า http://localhost/bunny-love/ หรือดับเบิลคลิก index.html ได้ทันที

## แก้รูป ชื่อ และข้อความ

เปิด `config.js` ด้วย VS Code หรือ Notepad แล้วบันทึกเป็น UTF-8:

- `recipient` ชื่อเธอ / `sender` ชื่อคุณ
- `photoUrl` ลิงก์ภาพโดยตรงจาก Discord หรือชื่อไฟล์ เช่น `assets/our-photo.jpg`
- `photoCaption` คำบรรยายรูป
- `texts` ข้อความแต่ละส่วน แก้เฉพาะด้านขวาในเครื่องหมายคำพูด ใช้ `\n` ขึ้นบรรทัดใหม่
- `notReadyMessage` ข้อความเมื่อเธอขอเวลา
- `noPhotoTitle` หัวข้อของขวัญเมื่อยังไม่ได้ใส่รูป

รูปเดียวกันจะปรากฏในของขวัญและกรอบความทรงจำ ถ้ายังไม่มีรูปจะใช้สวนกระต่ายที่แถมมา ถ้ารูปเปิดไม่ได้จะมีภาพสำรองและข้อความแจ้ง ถ้าข้อความใหม่ยังไม่ปรากฏ ให้รีเฟรชด้วย Ctrl+F5

ใช้ลิงก์ตัวรูปจาก Discord ไม่ใช่ลิงก์ข้อความหรือห้องสนทนา หากวันหลังลิงก์เปิดไม่ได้ ให้แทนที่ด้วยลิงก์ใหม่หรือบันทึกรูปไว้ใน assets เพื่อไม่ต้องพึ่งลิงก์ภายนอก

## ใช้กับ GitHub Pages

นำไฟล์ทั้งหมดภายในโฟลเดอร์นี้ขึ้น repository โดยให้ index.html อยู่ระดับบนสุด ตั้ง GitHub Pages ให้เผยแพร่จาก branch ที่เก็บไฟล์และโฟลเดอร์ root ไม่ต้องใช้ npm หรือ build มี .nojekyll มาให้แล้ว

## สิ่งที่มี

ฉากเปิดเต็มจอ / ภาพสวนกระต่ายเฉพาะเว็บ / หัวใจฉลอง / การเผยเนื้อหาขณะเลื่อน / กล่องของขวัญ / รูปจากลิงก์ / จดหมาย / คำถามพร้อมสองคำตอบ / ดนตรีสังเคราะห์เปิดปิดได้ / รองรับมือถือ คีย์บอร์ด และการลดแอนิเมชันตามระบบ

เสียงเริ่มเมื่อกดเปิดเสียงเท่านั้น ไม่มีการส่งคำตอบออกจากเครื่องหรือเก็บข้อมูลผู้ชม ฟอนต์โหลดจาก Google Fonts หากออฟไลน์จะใช้ฟอนต์ระบบ ตัวเว็บยังทำงานได้

ปรับรูปลักษณ์ใน style.css และโครงสร้างใน index.html ได้ตามต้องการ
